# CampusFix AI Prototype

Open `frontend/index.html` for the working offline demo.

Run the mock API:
`python backend/server.py`

The project is intentionally simulated and safe for expo use. No real university infrastructure is modified.

Core flow:
Understand -> Diagnose -> Retrieve -> Tool -> Verify -> Resolve/Ticket -> Correlate -> Escalate.

The source PDF defines CampusFix's first-level autonomous IT support baseline; this prototype implements that baseline and the agreed differentiators.
