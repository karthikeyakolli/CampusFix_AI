## PDF-grounded baseline
The source brief specifies CampusFix as a first-level autonomous IT support assistant that understands the problem, asks diagnostic questions, searches the IT knowledge base, recommends troubleshooting, determines whether it is resolved, creates a ticket if required and escalates complex issues. It explicitly highlights RAG + tool usage + agent reasoning. The prototype follows that baseline.
